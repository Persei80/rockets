# Мои ракеты

Личный дневник маленьких долгосрочных ставок на молодые компании. Программа ничего не покупает сама: покупки делаются у брокера, а здесь записываются и отслеживаются.

## Что умеет

- **Портфель** — что куплено, сколько стоит сейчас в шекелях, во сколько раз выросло. Шкала-«ракета» от ×1 до ×100 для каждой компании.
- **Наблюдаю** — кандидаты (например, из ежемесячного отчёта): заметка «чем интересна», риск, источник и изменение цены с дня добавления. Предупреждает, если компания уже стоит больше $2 млрд.
- **Окно компании** — график с периодами от 1 дня до «всё время», мои покупки и средняя цена на графике, моя позиция, личная заметка, рыночная стоимость.
- **Машина времени** — «что было бы, если бы я вложил N ₪ тогда»: разово или каждый месяц, с самым сильным падением и временем восстановления.
- **План** — месячный бюджет, привычка «месяцев подряд», вложения по месяцам, распределение денег по компаниям, свои правила.
- Покупки в шекелях по курсу дня покупки (курс и цена на прошлую дату подставляются сами), дробные акции, комиссия брокера, продажи.
- Резервная копия в файл и загрузка из файла. Тёмная и светлая тема, телефон, установка как приложение.

## Данные

- Цены, поиск и графики: публичные адреса CNBC (`quote.cnbc.com`, `symlookup.cnbc.com`, `ts-api.cnbc.com`), без ключа.
- Курс доллара: CNBC (`ILS=`), запасной и исторический — Европейский центробанк через [Frankfurter](https://frankfurter.dev).
- Все записи хранятся только в браузере (`localStorage`, ключи с префиксом `rk.`).

## Запуск у себя

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка, окна (компания, покупка, наблюдение, настройки, справка) |
| `style.css` | Оформление: светлая/тёмная тема, телефон |
| `js/app.js` | Запуск, вкладки, обновление экрана |
| `js/api.js` | Котировки, поиск, история цен, курс доллара |
| `js/live.js` | Регулярное обновление цен |
| `js/calc.js` | Расчёт портфеля, «ракеты», машины времени |
| `js/store.js` | Хранение данных, резервная копия |
| `js/portfolio.js`, `js/watch.js`, `js/machine.js`, `js/plan.js` | Разделы |
| `js/detail.js`, `js/chart.js` | Окно компании и графики |
| `js/forms.js` | Формы покупки/продажи, наблюдения, настроек |
| `manifest.webmanifest`, `sw.js`, `icons/` | Установка как приложение |

Это не финансовая рекомендация.
